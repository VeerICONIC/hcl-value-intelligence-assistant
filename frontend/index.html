How it works

Design principle: code for numbers, retrieval for charter evidence, the language model only for explanation

Route & answer

Metric → templates · narrative → hybrid retrieval + Nova Lite · guards

🔢 No invented numbers

Metric answers are templates filled by code. Narrative LLM output containing any digit is rejected (retry once, then cited excerpts).

🛡️ Charter injection

Instruction-like lines are flagged at indexing and removed before prompting; charter text is always treated as data.

🔒 Personal data & gaps

Personal-detail requests are refused. Missing evidence returns exactly “I do not have that in the data provided”.
